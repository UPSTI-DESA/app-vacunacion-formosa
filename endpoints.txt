Todos los Endpoints
BASE: https://dh.formosa.gob.ar/modulos/webservice/php/

1. Validar Version de la App

GET /versionapp/wserv_versiones_app.php
Parametro	Tipo	Descripcion
sysappl01_nombre	String	Nombre de la app
sysappl01_version	String	Version actual (ej: 3.0.0)
Ejemplo:


GET https://dh.formosa.gob.ar/modulos/webservice/php/versionapp/wserv_versiones_app.php?sysappl01_nombre=vacunacion&sysappl01_version=3.0.0
Respuesta:


{
  "versiones": [
    {
      "sysappl01_nombre": "vacunacion",
      "sysappl01_version": "3.0.0",
      "codigo_mensaje": "0",
      "mensaje": "OK"
    }
  ]
}

Body (form-urlencoded):

insertvacunado	JSON serializado como string (ver abajo)
